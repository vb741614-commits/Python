# Bhardwaj wedding invitation

## Run locally

Install the dependencies and start the Python web server:

```powershell
python -m pip install -r requirements.txt
python app.py
```

Open `http://localhost:5000` in a browser.

## Publish on Render

The repository-root `render.yaml` is configured for this app. Push the project to GitHub, sign in to Render, choose **New > Blueprint**, connect the repository, and deploy the `bhardwaj-wedding-invitation` service. Render will provide its public `onrender.com` URL when the deployment is ready. Share that URL to open the invitation from anywhere.

The free Render service may go to sleep after inactivity, so its first visit after a quiet period can take a little longer to load.
